-- What was NOT verified by this demonstration -----------------------------------------

  OpenCode is not running on this host, so the OpenCode-dependent behaviour is unproven
  end to end (the Core reports the agent as "offline", which is correct and is what the
  island shows). The Core's own 13 OpenCode tests skip with that reason rather than
  passing.

  The chat demonstration (Test 2-4: "what agents are connected?", "what is Hermes
  doing?") was verified at the transport level with the app's own client, against the
  live Core - see ui-core-link-probe.txt - not by typing into the island. The island's
  chat still goes through Rust (claude.rs -> Core /chat), which was already working.
