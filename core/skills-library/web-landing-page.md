# Web Landing Page Skill

## Purpose
Plan and improve website landing pages with better structure, clarity, and visual hierarchy.

## When to use
Use this skill when designing or refining landing pages, marketing websites, or homepage sections.

## Inputs
- product or brand context
- target audience
- page goal
- existing content or screenshot

## Output
Return:
- recommended structure
- hero section direction
- CTA hierarchy
- UI text and layout suggestions
- visual style ideas

## Constraints
- keep the message clear and conversion-focused
- prioritize readability and visual hierarchy
- avoid decorative clutter that reduces focus

## Examples
- Improve a product landing page
- Rewrite a homepage structure for a SaaS startup
- Suggest a more polished hero section for a designer portfolio
