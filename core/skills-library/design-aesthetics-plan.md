# Design Aesthetics Planning Skill

## Purpose
Plan aesthetic direction for websites and product experiences with a unified visual and emotional strategy.

## When to use
Use this skill when defining design direction, mood boards, visual systems, or high-level aesthetic planning.

## Inputs
- product identity
- target user persona
- desired emotional tone
- existing visual references

## Output
Return:
- a design direction summary
- recommended palette and typography ideas
- mood and atmosphere guidance
- layout and composition recommendations

## Constraints
- stay coherent with the brand
- keep the aesthetic practical and implementable
- avoid trend-only design choices that conflict with usability

## Examples
- Plan the visual style of a portfolio website
- Recommend a visual direction for a developer tool landing page
- Define an aesthetic system for a motion-heavy SaaS homepage
